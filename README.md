# CodeAlpha — Task 2: Basic Network Sniffer

## What This Project Does
A Python-based Network Packet Sniffer that captures live network traffic.
Built using the Scapy library for CodeAlpha Cyber Security Internship.

## Features
- Captures TCP, UDP, ICMP and ARP packets
- Shows Source and Destination IP addresses
- Shows ports, flags, TTL and packet size
- Detects HTTP, HTTPS, SSH, FTP and DNS traffic
- Colour-coded terminal output
- Live packet count summary

## How to Run

Step 1 - Install the library:
pip install scapy

Step 2 - Run as Administrator:
python network_sniffer.py

## Libraries Used
- Scapy (packet capture)
- Python 3.12

## Note
Only use on networks you own. This tool is for educational purposes only.
